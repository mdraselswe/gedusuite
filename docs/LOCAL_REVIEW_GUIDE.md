# লোকালি সব আপডেট দেখার গাইড (ধাপে ধাপে)

> এই গাইডের সবকিছু আপনার কম্পিউটারের **লোকাল ডেটাবেসে** চলে। আপনার আসল
> প্রোডাকশন ডেটাবেস বা GeduShop ওয়েবসাইটে কিছুই যায় না।

## ধাপ ০ — একবারের প্রস্তুতি

প্রজেক্ট ফোল্ডার: `E:\Code\Personal\gedusuite`, ব্রাঞ্চ `saas-upgrade`।

```bash
git checkout saas-upgrade
yarn install
```

## ধাপ ১ — চালু করা (৪টি কমান্ড, ক্রমানুসারে)

| # | কমান্ড | কী করে | টার্মিনাল |
|---|---|---|---|
| ১ | `yarn db:local` | লোকাল ডেটাবেস চালু | **খোলা রাখুন** (বন্ধ করবেন না) |
| ২ | `yarn local:migrate` | টেবিল তৈরি | শেষ হলে বন্ধ |
| ৩ | `yarn demo:seed` | ডেমো ব্যবসা তৈরি (~১.৫ মিনিট) | শেষ হলে বন্ধ |
| ৪ | `yarn local:dev` | অ্যাপ চালু | **খোলা রাখুন** |

তারপর ব্রাউজারে খুলুন: **http://localhost:3000**

- প্রথমবার প্রতিটি পেজ খুলতে ১–২ মিনিট লাগতে পারে (ডেভ মোড কম্পাইল করে)। একবার খোলার
  পর দ্রুত।
- **দ্রুত দেখতে চাইলে** (প্রোডাকশন মোড, সব পেজ ১–২ সেকেন্ড):
  ```bash
  npx dotenv -e .env.saas.local -- npx next build --webpack     # ~৫–১০ মিনিট, একবার
  yarn local:start                                                # ৪ নম্বরের বদলে
  ```
  > প্রোডাকশন-মোডে ইমেইলের লিংক টার্মিনালে **ছাপা হয় না** (শুধু সতর্কতা)। সাইন-আপ/পাসওয়ার্ড-রিসেট
  > দেখতে হলে `yarn local:dev` ব্যবহার করুন।
- `yarn test:integration` চালালে লোকাল ডেটাবেস **মুছে যায়** → পরে আবার `yarn demo:seed`।

## ধাপ ৩ — কোন আপডেট কোথায় দেখবেন

### ক. নতুন ডিজাইন (ফেজ ৫) — লগইন করার পর সব পেজেই
- **বামে গাঢ় নেভি সাইডবার**, সক্রিয় পেজে সবুজ-নীল দাগ।
- বড় সংখ্যা/শিরোনামে নতুন ফন্ট (Bricolage)।
- **Dashboard** → `/little-nest/dashboard`
- **অর্ডার** → `/little-nest/sales/orders`: Status/Payment ফিল্টারে এখন "All" দেখায় (আগে
  `__all__`)।
- **Reports** → `/little-nest/reports`: উপরের ৬টি বক্সে এখন ৳ ও কমা (আগে `137110.00`)।
- ছোট স্ক্রিনে দেখতে: ব্রাউজারে F12 → ফোন আইকন, অথবা ফোনে `http://<আপনার-পিসির-IP>:3000`।

### খ. পাবলিক সাইট (ফেজ ৪) — **লগআউট করে** দেখুন (বা Incognito উইন্ডো)
| কী | ঠিকানা |
|---|---|
| ল্যান্ডিং পেজ | http://localhost:3000/ |
| প্রাইসিং | http://localhost:3000/pricing |
| Terms / Privacy / Refund | `/terms`, `/privacy`, `/refund` |

ল্যান্ডিংয়ের ডানদিকের "Order #1042" স্লিপের সংখ্যাগুলো অ্যাপের আসল হিসাবের
ফাংশন দিয়ে গণনা করা।

### গ. সাইন-আপ, ইমেইল ভেরিফাই, পাসওয়ার্ড রিসেট (ফেজ ১)
লোকালি ইমেইল **পাঠানো হয় না** — ইমেইলের লিংক **`yarn local:dev` চালানো টার্মিনালে ছাপা হয়**।

1. `/register` → নতুন নাম/ইমেইল/পাসওয়ার্ড (৮+ অক্ষর) দিয়ে অ্যাকাউন্ট খুলুন।
2. টার্মিনালে `[mailer] (dev) to=... ` খুঁজুন → নিচের `/verify-email/...` লিংকটি ব্রাউজারে
   খুলুন → **"Confirm my email"** বাটন চাপুন।
3. যাচাই ছাড়া উপরে হলুদ ব্যানার দেখাবে ("Please confirm your email…") এবং **নতুন workspace
   বানানো যাবে না**।
4. পাসওয়ার্ড ভুলে গেলে: `/forgot-password` → টার্মিনালে লিংক → নতুন পাসওয়ার্ড।
5. লগইনে ১০ বার ভুল পাসওয়ার্ড দিলে ১৫ মিনিটের জন্য আটকে যায় (থ্রটল)।

### ঘ. নতুন workspace + অনবোর্ডিং + ট্রায়াল (ফেজ ৩ ও ৪)
1. নতুন ইউজার দিয়ে লগইন (গ-তে বানানো, ভেরিফাই করা) → **New workspace** → একটি নাম দিন।
2. Dashboard-এ **"Get your shop set up"** চেকলিস্ট (পণ্য → ক্রয় → প্রথম অর্ডার)।
3. বামে **Plan & billing**: ১৪ দিনের ট্রায়াল, ব্যবহার বনাম লিমিট।
   → http://localhost:3000/&lt;workspace-slug&gt;/settings/billing

### ঙ. পেমেন্ট ও প্ল্যাটফর্ম অ্যাডমিন (ফেজ ৩)
`demo@gedusuite.test` লোকালি প্ল্যাটফর্ম অ্যাডমিন (`.env.saas.local`-এ সেট করা)।

1. নতুন workspace-এর মালিক হিসেবে **Plan & billing** → একটি প্ল্যান বেছে নিন → একটি
   বানানো Transaction ID (যেমন `TEST123456`) দিয়ে **"I have paid"**।
2. লগআউট → `demo@gedusuite.test` দিয়ে লগইন → http://localhost:3000/admin/payments
   → **Approve & activate**।
3. http://localhost:3000/admin — সব workspace: প্ল্যান বদল, +7/+30 দিন, Suspend/Restore।
4. আগের ইউজার দিয়ে ফিরে Plan & billing-এ দেখুন প্ল্যান সক্রিয় ও মেয়াদ বসেছে।

### চ. প্ল্যান লিমিট ও "রিড-অনলি" দেখতে (ঐচ্ছিক)
ডিফল্টে লিমিট **বন্ধ**। চালু করতে `.env.saas.local`-এ `# BILLING_ENFORCEMENT="on"` লাইনের `#`
তুলে দিন, `yarn local:dev` রিস্টার্ট করুন। তারপর:
- নতুন workspace (Starter প্ল্যান অ্যাডমিন থেকে সেট করে): ২য় কুরিয়ার বা ২য় মেম্বার ইনভাইট
  → "Your Starter plan includes 1 …" বার্তা।
- অ্যাডমিন থেকে **Suspend** → ওই workspace-এ কিছু যোগ করতে গেলে "read-only" বার্তা;
  তবুও সব ডেটা দেখা যায়, ব্যাকআপ নামানো যায়।
- ট্রায়াল-ব্যানার (শেষ ৫ দিন) ও মেয়াদ-শেষ ব্যানার উপরে দেখাবে।

### ছ. অন্যান্য নতুন জিনিস (বামের মেনুতে)
| মেনু | কী | ঠিকানা |
|---|---|---|
| **Website** | নিজের WooCommerce সংযোগ, ওয়েবহুক URL/secret (শুধু মালিক) | `/little-nest/settings/website` |
| **Plan & billing** | প্ল্যান, লিমিট, পেমেন্ট ইতিহাস | `/little-nest/settings/billing` |
| **Help & support** | সাপোর্টে মেসেজ (টার্মিনালে মেইল ছাপা হয়) | `/little-nest/help` |
| **Appearance** (নিচে) | **Delete my account** | `/little-nest/settings/appearance` |

## ধাপ ৪ — স্বয়ংক্রিয় যাচাই (ইচ্ছা হলে)

```bash
yarn test               # ৬২১টি ইউনিট টেস্ট
yarn test:integration   # ৫৯টি (ডেমো ডেটা মুছে যাবে → পরে yarn demo:seed)
yarn typecheck
```

`tests/integration/` ফোল্ডারে দেখুন: `golden` (আর্থিক ফিগার অপরিবর্তিত),
`integrity` (বই মেলে), `roles-and-tenants` (রোল/টেন্যান্ট সুরক্ষা), `billing`, `auth`, `woo`।

## সমস্যা হলে

| লক্ষণ | সমাধান |
|---|---|
| লগইন হয় না / "connection refused" | `yarn db:local` টার্মিনাল বন্ধ হয়ে গেছে → আবার চালান |
| ডেমো workspace নেই | `yarn demo:seed` আবার চালান |
| "Too many attempts" | ১৫ মিনিট অপেক্ষা, অথবা `yarn demo:seed` (ডেটা রিসেট) |
| পেজ অনেকক্ষণ লোড | প্রথমবারের কম্পাইল — অপেক্ষা করুন, বা প্রোডাকশন-মোড ব্যবহার করুন |
| পোর্ট 3000 ব্যস্ত | পুরোনো `next` প্রসেস বন্ধ করুন বা পিসি রিস্টার্ট |
